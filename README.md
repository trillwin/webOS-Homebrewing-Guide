# How to Homebrew your LG webOS TV.
Here is the guide to Homebrewing a LG TV
## Developer Mode
1. Install Developer Mode from the LG Content Store
2. Make a LG Developer Account from https://webostv.developer.lge.com and click sign in
<img width="1852" height="802" alt="Opera Snapshot_2026-06-03_124358_webostv developer lge com" src="https://github.com/user-attachments/assets/7e6ced60-3d8a-4315-9b74-4e768b599fa4" />
3. Input your User ID (Email) and Password into Developer Mode, then click Login
4. Turn On "Dev Mode Status" and "Key Server" (The TV will restart once you turn on Dev Mode Status).

## Homebrewing
1. Go to https://github.com/webosbrew/dev-manager-desktop to get the Dev Manager App and go through the installation
2. Link the app to your device by inputting the device name or name, the Address, the passphrase. and set the authentication to "Dev Mode"

3. Click Save
4. You are ready
